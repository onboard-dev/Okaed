# Okaed Partner Center 更新手順

新しい .msix ができたあとに、Microsoft Store へ更新を申請する手順です。
(.msix の作り方は「ストア更新手順.md」を参照)

> 画面の表示名は Partner Center の更新で変わることがあります。似た名前の項目を選んでください。

## 用意するもの
- 新しい .msix(例: `MSIX\onboardjapan.Okaed_1.0.1.0_x64__....msix`)
- `Claude outputs\StoreArt\` の画像(アイコンを変えたときだけ)
  - BoxArt_1080x1080.png / BoxArt_2160x2160.png(1:1 ボックスアート)
  - PosterArt_720x1080.png / PosterArt_1440x2160.png(2:3 ポスターアート)
- 新しい画面のスクリーンショット(見た目が変わったときだけ。1366×768 以上の PNG)
- 「このバージョンの新機能」に書く文章(下に 1.0.1 の例あり)

## 手順

### 1. 更新の申請を始める
1. https://partner.microsoft.com/dashboard にサインイン
2. 「アプリとゲーム」→ **Okaed** を開く
3. アプリの概要ページで、公開中の申請の横にある「**更新**」(または「新しい申請を作成」)を押す
   - 前回の申請内容がコピーされた新しい申請が作られる。変えたいところだけ直せばよい

### 2. パッケージ
1. 申請ページの「**パッケージ**」を開く
2. 新しい .msix をドラッグ&ドロップ(または「参照」で選択)
3. アップロード後の検証でエラーが出ないことを確認
   - 「バージョンが前回以下」というエラー → MSIX のバージョンを上げ忘れている
4. 一覧に残っている **古いパッケージ(1.0.0.0 など)を削除**
5. 「保存」

### 3. ストア登録情報(アイコンや見た目を変えたときだけ)
1. 申請ページの「**ストア登録情報**」→「**日本語**」を開く
2. 「**このバージョンの新機能**」に更新内容を書く(例は下記)
3. 「**ストアのロゴ**」(またはストア用画像)の欄で
   - 2:3 ポスターアート → PosterArt_720x1080.png と PosterArt_1440x2160.png
   - 1:1 ボックスアート → BoxArt_1080x1080.png と BoxArt_2160x2160.png
   - 古い画像があれば削除して差し替える
4. 見た目が変わったならスクリーンショットも差し替える
5. 説明文の動作環境に「Windows 11 のみ」と書いていなければ追記しておく
6. 「保存」
   - 英語など他の言語の登録情報がある場合は、同じように更新する

### 4. 申請オプション(通常は変更不要)
- 「**制限付き機能**」(runFullTrust)の理由欄は前回の文面がそのまま引き継がれる。消えていたら前回の文面を貼り直す
- 公開日を指定したいときは「公開の保留オプション」で設定(指定しなければ審査が通りしだい自動公開)

### 5. 提出
1. 申請ページの全項目が「完了」になっていることを確認
2. 「**ストアに提出**」を押す
3. 認定(審査)が始まる。状況は申請ページで確認できる
   - 通常は数時間〜1日程度、最大で3営業日ほどかかることがある
   - 不合格のときは理由がメールと申請ページに出るので、直して再提出

### 6. 公開後の確認
- ストアの Okaed のページで、バージョン・アイコン・画像が新しくなっているか確認
- 自分の PC で Microsoft Store →「ライブラリ」→「更新プログラムを取得」で 1.0.1 に更新し、動作を確認
  - .txt などを右クリック →「プログラムから開く」に Okaed が出るか
  - 「設定 → アプリ → 既定のアプリ」で Okaed を選べるか

## 「このバージョンの新機能」の例(1.0.1)

```
・.txt / .md / .log / .ini / .csv / .xml を Okaed で開けるようになりました(既定のアプリにも設定できます)
・インスタントブックマーク:Ctrl+1～9 で行を記憶し、もう一度押すとジャンプ
・ファイルメニューに「拡張子の変更」を追加
・数値・英字・記号の色を、プレビューを見ながら RGB で設定できるダイアログを追加
・Ctrl+A ですべて選択
・Markdown プレビューで絵文字をカラー表示
・空白可視化やブックマーク表示時のスクロールを高速化
・アイコンを新しくしました
```
