# Okaed ストア更新(MSIX)手順

前提: MSIX Packaging Tool の「パッケージ エディター」で前回の MSIX を開き、中身を**上書きで**差し替えて保存する方式。

## 用意するもの(Okaed フォルダ)
- `Okaed.exe` … `set-version.bat` → `build.bat` で作り直したもの
- `MSIX\AppxManifest.xml` … ファイル関連付け(.txt / .md / .log / .ini / .csv / .xml)入りのマニフェスト。**関連付けを変えるときだけ使う**
- `MSIX\<版>\Assets\` … ロゴ一式 40 ファイル(元パッケージと同じファイル名・同じサイズ)。**アイコンを変えるときだけ使う**
- `Claude outputs\StoreArt\` … BoxArt(1080/2160)、PosterArt(720x1080/1440x2160)

## 手順
1. `set-version.bat` でアプリのバージョン(例 1.0.1)→ `build.bat` → Okaed.exe を起動してタイトル・アイコン・新機能を確認
2. MSIX Packaging Tool → タスクの選択で「**パッケージ エディター**」(既存のパッケージを編集する)→ **前回ストアに出した .msix** を開く
   - 「変更パッケージ」は別物なので使わない
3. **パッケージ情報**: バージョンを x.y.z.0 に上げる(前回より大きく)。署名の基本設定は「パッケージに署名しない」(ストアが署名する)
   - バージョンはこの欄で変えればマニフェストにも自動で反映される
4. **パッケージ ファイル**(左メニュー)で exe を上書きする
   - `Package` → `VFS` → `ProgramFilesX64` → `Okaed` を開く
   - **`Okaed` フォルダを右クリック →「ファイルの追加」**で新しい `Okaed.exe` を選ぶ → 置き換えを確認されたら「はい」
   - ⚠ 先に Okaed.exe を「削除」しないこと。空になった `Okaed` / `ProgramFilesX64` フォルダが自動で消え、追加先がなくなる。消してしまったら「キャンセル」で破棄して手順2から開き直す
5. (アイコンを変えるときだけ)同じ画面で **`Assets` のロゴを上書き**
   - `Assets` フォルダを右クリック →「ファイルの追加」で `MSIX\<版>\Assets` の 40 ファイルを選ぶ → 置き換えを「はい」
   - こちらも削除してから追加はしない
6. (関連付けを変えるときだけ)**パッケージ情報 → マニフェスト ファイル →「ファイルを開く」** → メモ帳の中身を `MSIX\AppxManifest.xml` の内容で丸ごと置き換え → 上書き保存してメモ帳を閉じる → パッケージ情報のバージョンが手順3の値か確認
   - パッケージ エディターには外部のマニフェストを読み込む機能がなく、関連付けを編集する画面もないため、この方法しかない
   - 1.0.1 で関連付けを入れたので、以降は前回の .msix に引き継がれる。関連付けを変えない限り不要
7. 右下の「**保存**」→ 新しい .msix を作成(保存先は MSIX フォルダ)
8. Partner Center → アプリ → 新しい申請 → パッケージ: 新 .msix をアップロードし旧パッケージを削除 → ストア登録情報: BoxArt / PosterArt を登録 → 申請

通常のバージョンアップ(機能追加のみ)は **手順 1 → 2 → 3 → 4 → 7 → 8** だけでよい。

## うまくいかないとき
- 上書きで追加できない場合: エクスプローラーで `ProgramFilesX64\Okaed\Okaed.exe` の形のフォルダを作り、`VFS` を右クリック →「フォルダーの追加」でそのフォルダを追加。展開の場所が `[{ProgramFilesX64}]\Okaed\Okaed.exe` になっていれば OK(マニフェストの起動パスは `VFS\ProgramFilesX64\Okaed\Okaed.exe`)

## メモ
- Resources.pri はファイル名で画像を参照するので、同名で差し替えれば作り直し不要
- runFullTrust の申請理由は前回と同じ文面でよい
- .bat / .ps1 などは関連付けに入れない(既定アプリにするとダブルクリックで実行されなくなるため)
