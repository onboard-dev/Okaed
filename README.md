# 🏡 Okaed — シンプルで軽快なテキストエディタ

いろいろなエディタを試しても、結局いちばん使うのはシンプルで必要な機能だけのエディタ。
そんな「おかえり」と言えるエディタを目指して作りました。

📦 **インストール不要**。`Okaed.exe` をダブルクリックするだけで動きます(.NET Framework 4.8 / Windows 標準機能のみ、外部ライブラリなし)。

🖥️ **対応OS**: Windows 11 のみ

---

## ✨ 特長

- 🗂️ **タブで複数ファイルを同時に編集** — ファイルを開くたびにタブが増え、クリックや Ctrl+Tab で切り替え。タブはドラッグで並べ替え、×・中クリック・Ctrl+W で閉じる。未保存のタブには ● が付き、元に戻す履歴・検索結果・ブックマーク・Markdown プレビューの表示もタブごとに保持。開いているファイルが 1 つだけのときはタブを隠して、編集領域を広く使えます
- 🔍 **検索** — 入力と同時に一致箇所を黄色くハイライト。`.*` で正規表現、`Aa` で大文字・小文字を区別。件数もひと目で分かる
- 🔁 **置換** — 1件ずつでも、まとめてでも。置換ミスしても Ctrl+Z でまとめて元通り
- 👀 **空白の可視化** — 半角スペース・全角スペース・タブ・改行を記号で表示(ファイルの中身は変わりません)
- 🔤 **半角⇔全角 変換** — 数字・英字・記号・カタカナに対応、選択範囲だけをワンクリック変換
- 🎨 **数値・英字の自動着色** — コードや数字混じりの文章がぐっと読みやすくなる。「表示 → 数値・英字・記号の色」で RGB(0～255)をプレビューしながら調整
- 🌗 **ライト/ダーク テーマ** — 背景・文字・数値・英字・記号の色をそれぞれ自由にカスタマイズ可能
- 📖 **Markdown プレビュー** — F12キーで左右に並べて表示、スクロールも連動
- 🈶 **文字コード対応** — Shift_JIS / UTF-8(BOM付き)。BOMなしUTF-8も読み込みOK
- ↩️ **Undo/Redo** — 気兼ねなく書いて、気軽に戻せる
- 🕒 **日付・時刻をワンクリック挿入**
- 🔖 **インスタントブックマーク** — Ctrl+1～9 で現在の行を記憶、もう一度押すとその行へジャンプ(同じ行で押すと解除)。エディタ左側に 1️⃣～9️⃣ を表示し、ファイルごとに記憶
- 🏷️ **拡張子の変更** — 「ファイル → 拡張子の変更」で .txt ⇔ .md などをその場で変更(履歴・ブックマークも引き継ぎ)
- 🗂️ **最近使ったファイル** — 直近30件を記録、すぐ開き直せる
- 💾 **自動保存** — 元のファイルには触れずバックグラウンドでこっそり保存、もしもの時だけ復元を確認
- 🖱️ **編集エリアのトリプルクリック** — ウィンドウサイズをワンクリックで既定サイズに戻せる
- 🫥 **タスクトレイに最小化** — ESCで隠れて、Ctrl+Shift+O でどこからでも即復帰

## ⌨️ ショートカット

| キー | 動作 |
|---|---|
| Ctrl+F / Ctrl+H | 検索欄 / 置換欄へ |
| Enter / Shift+Enter(検索欄) | 次 / 前を検索 |
| F3 / Shift+F3 | 次 / 前を検索 |
| Enter / Ctrl+Enter(置換欄) | 置換 / すべて置換 |
| Esc | (検索/置換/フォント欄なら)本文へ戻る / (それ以外)タスクトレイに最小化 |
| Ctrl+Shift+O | タスクトレイから復帰(いつでも有効) |
| Ctrl+N / O / S / Shift+S | 新規(新しいタブ) / 開く(複数選択可) / 保存 / 名前を付けて保存 |
| Ctrl+Shift+N | 新しいウィンドウ |
| Ctrl+W | タブを閉じる |
| Ctrl+Tab / Ctrl+Shift+Tab(Ctrl+PageDown / PageUp) | 次 / 前のタブへ |
| F12 | Markdown プレビュー表示切替 |
| Ctrl+1～9 | ブックマーク:未設定なら現在の行に設定 / 別の行にあればそこへ移動 / 同じ行なら解除 |

ファイルはウィンドウへドラッグ&ドロップ(複数可)、または `Okaed.exe ファイル名` でも開けます。開いたファイルはそれぞれ新しいタブになり、すでに開いているファイルはそのタブに切り替わります。
Okaed がすでに起動しているときは、エクスプローラーなどから開いたファイルも、起動中のウィンドウの新しいタブで開きます(別のウィンドウで作業したいときは「ファイル → 新しいウィンドウ」)。
設定(フォント・ウィンドウ位置・ファイル履歴・テーマ・ブックマークなど)は `%APPDATA%\Okaed\okaed.ini` に保存されます。保存されたブックマークは「編集 → すべてのブックマークを削除」でまとめて消せます。

## 🛠️ ソースからビルドする場合

- **インストール不要**: `build.bat` をダブルクリック(Windows 標準の `csc.exe` を使用)
- **Visual Studio**: `Okaed.csproj` を開いてビルド
- 🏷️ **バージョン番号の設定**: `set-version.bat` をダブルクリックし、表示されるプロンプトにバージョン番号(例: `1.0.0`)を入力すると `Version.cs` が更新され、ビルド後のメインウィンドウのタイトルに `Okaed Version 1.0.0` のように表示されます

| ファイル | 内容 |
|---|---|
| `MainForm.cs` | 画面・検索/置換・ファイル操作・プレビュー・履歴・自動保存・トレイ |
| `MainForm.Tabs.cs` | 複数文書のタブ管理(タブごとの状態、切り替え、閉じる) |
| `TabBar.cs` | タブの帯(テーマ対応の自前描画、ドラッグ並べ替え) |
| `SingleInstance.cs` | 単一インスタンス化(起動中のウィンドウへファイルを渡す) |
| `MainForm.Bookmarks.cs` | インスタントブックマーク(Ctrl+1～9、左側の番号表示、ini への保存) |
| `Dialogs.cs` | 数値・英字・記号の色ダイアログ、拡張子の変更ダイアログ |
| `EditorBox.cs` | 編集部品(独自Undo、ハイライト、空白可視化、着色) |
| `Markdown.cs` | Markdown → HTML 変換 |
| `TextFile.cs` | SJIS / UTF-8(BOM) の読み書き |
| `HalfFullWidth.cs` | 半角/全角の相互変換 |
| `Settings.cs` | 設定の保存 |
